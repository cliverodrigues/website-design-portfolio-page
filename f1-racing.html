F1 Racing Agent — teaching a car to lap a circuit

A custom Gymnasium environment I built from scratch in Python and NumPy. An F1-style car reads the track through seven distance sensors and decides how to steer, accelerate and brake. A PPO agent from Stable Baselines3 learns to drive it by trial and error.

How the environment works

Standard Gymnasium API: reset() → step(action)

Observation — 10 numbers

  • 7 sensor rays (−90° … +90°) measuring distance to the track edge
  • Current speed
  • Heading error vs. the track direction
  • Offset from the centre line

Action — 2 numbers

  • Steering, −1 (right) to +1 (left)
  • Pedal, −1 (full brake) to +1 (full throttle)

Reward

  • +0.1 per metre of progress along the track
  • −0.01 per step, so slower laps score less
  • −10 for leaving the track, which ends the episode
  • +50 per completed lap

Physics

A kinematic bicycle model with a ~3.5 g tyre-grip limit. If the car enters a corner too fast it understeers wide, so the agent has to learn to brake before the turn. That is the core skill of racing.

import gymnasium as gym
import f1_gym  # registers "F1Track-v0"

env = gym.make("F1Track-v0")
obs, info = env.reset(seed=0)

while True:
    action = env.action_space.sample()   # or: model.predict(obs)
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        break

print(info["lap_times"], info["speed_kph"])

Engineering notes & results

Built to train fast on a laptop CPU, no GPU needed

Vectorised geometry

Sensor rays are intersected exactly with the track edges using 2D cross products in NumPy, with no Python loops. That made each step about 18× faster than my first ray-marching version.

Local search

Each step only tests the stretch of track near the car, not all 400 segments. This keeps the cost per step flat however long the circuit is.

Progress, not speed

The reward pays for metres along the centre line, so the agent can't exploit it by spinning in circles or driving backwards.

Tested

It passes Gymnasium's check_env. Pytest covers seeding, crash detection, sensor sanity checks and a full baseline lap.
